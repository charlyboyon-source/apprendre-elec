LEXIQUE DE L'ÉLECTRICIEN

Mode de charge

Façon de recharger un véhicule. Mode 2 : prise avec boîtier de contrôle sur le câble. Mode 3 : borne dédiée qui dialogue avec le véhicule. Mode 4 : charge rapide en courant continu.

🔧 Sur le chantier

Le mode 1, voiture branchée sur une prise ordinaire sans boîtier de contrôle, est à proscrire. Le mode 2 se fait sur une prise, de préférence renforcée, avec le boîtier de contrôle sur le câble. Le mode 3, sur borne dédiée, est la solution normale au domicile. Le mode 4 concerne la charge rapide en courant continu, sur les stations publiques.

À ne pas confondre avec

  • puissance de charge : le mode décrit la façon de charger ; la puissance (3,2 kW, 7,4 kW, 22 kW…) dépend du circuit et du matériel.

Dans les cours

On distingue les façons de recharger par leur mode de charge.
