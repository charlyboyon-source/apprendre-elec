LEXIQUE DE L'ÉLECTRICIEN

Norme NF C 18-510

Norme de prévention du risque électrique lors des opérations sur les installations : habilitations, consignation, zones d'environnement, EPI. À distinguer de la NF C 15-100, qui régit la conception des installations.

🔧 Sur le chantier

C'est elle qui fixe les symboles d'habilitation (B0, B1V, BR, BC…), les étapes de la consignation et les zones autour des pièces sous tension. Pour l'électricien, elle répond à la question « comment intervenir sans se blesser ? ». Le recyclage de l'habilitation est recommandé tous les 3 ans.

À ne pas confondre avec

  • NF C 15-100 : la NF C 15-100 dit comment concevoir et réaliser l'installation ; la NF C 18-510 dit comment travailler dessus en sécurité.
  • NF C 14-100 : la NF C 14-100 concerne le branchement, en amont de l'AGCP.

Dans les cours

Travailler sur une installation électrique, ou près d'elle, ne s'improvise pas : c'est encadré par la norme NF C 18-510.
