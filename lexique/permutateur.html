LEXIQUE DE L'ÉLECTRICIEN

Permutateur

Appareil à quatre bornes inséré sur les navettes, entre deux va-et-vient, pour ajouter un point de commande. Il transmet les navettes tout droit ou les croise.

🔧 Sur le chantier

On le place entre les deux va-et-vient, sur les navettes, pour commander une lampe depuis un troisième endroit : deux va-et-vient et un permutateur pour trois points, deux va-et-vient et deux permutateurs pour quatre. Au-delà de trois points, le télérupteur devient en général plus simple à câbler.

À ne pas confondre avec

  • va-et-vient : le va-et-vient a trois bornes et se place aux extrémités ; le permutateur en a quatre.

Dans les cours

Le permutateur possède quatre bornes : deux pour les navettes qui arrivent, deux pour les navettes qui repartent.

Module 17 · 5. Trois endroits : le permutateur

On peut continuer ainsi, mais le montage devient vite lourd : deux navettes à tirer d'un bout à l'autre, quatre fils dans chaque boîte de permutateur, et un dépannage délicat.
